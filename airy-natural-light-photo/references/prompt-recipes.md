# 提示词配方 · Prompt Recipes

以下为结构模板。方括号内容用用户照片的实际信息替换，无关子句删掉。

## 编辑模板（默认）

```text
用例：写真调色编辑，不重绘内容。
主请求：把提供的照片修成清新通透的日系自然光风格，仅调整曝光、色彩、光线与空气感，不改变画面内容。
源图：提供的图像是编辑目标与构图基准。
保留不变：[人物身份与五官、姿势、服装设计与主色、物件数量、建筑与透视、纵横比]。
场景描述：[平实描述照片里正在发生的事]。
光线逻辑：以原图的[窗光/逆光/阴天漫射/树荫斑驳]为唯一光源，顺着光源方向提亮阴影、柔化高光滚降，亮部带轻微空气辉光。
色调：[清新通透/日系奶油/湿润青调]——白平衡[中性微冷/中性微暖/阴影青调]，黑位轻抬升呈雾面灰而非死黑，全局低对比、极缓 S 曲线。
色彩映射：整体降饱和[10–25]%；绿色向茶绿黄绿偏移，蓝色向粉蓝雾蓝偏移，橙红仅作小面积点缀；肤色提亮通透、保留自然血色。
质感：[极细颗粒/无颗粒]，低于常规锐化，无晕影。
禁止：新增人物/物件/文字/水印；HDR 局部清晰度、橙青电影调、过暖黄渍、死黑、塑料皮肤、整体模糊、重绘内容。
```

## 生成模板（用户只给文字描述时）

```text
用例：日系自然光风格照片。
场景：[地点、时间、天气，如"清晨的日式公寓窗边"]。
主体与动作：[一个人/一件静物 + 一个安静的动作]。
相机视角：[35–50mm 视角，与日常视线齐平]，自然透视。
光线：[具体的自然光源与方向]，柔和、可信、有空气感。
色调：[模式名]，低对比、雾面阴影、奶白高光、降饱和底色 + 一个焦点色。
质感：细腻自然，无锐化痕迹，无文字与水印。
避免：摆拍感、HDR、橙青调、复古 sepia、过曝死白、塑料皮肤。
```

## 强度档位对照

- **轻调 Faithful**：在模板中删去辉光与颗粒句，把降饱和幅度压到 5–10%，禁裁切。
- **标准 Standard**：按模板默认执行。
- **通感 Dreamy Air**：允许逆光雾化加强、高光溢出感增强，但必须写明"保留一处清晰可读的焦点"。

## 现成配方

### 逆光草地人像

```text
把这张逆光人像修成清新通透风格：以画面后方的夕阳或天光为唯一光源，发丝轮廓保留一圈微光，面部由环境反光补亮；阴影雾面抬升，高光柔和滚降；整体降饱和，草地绿茶色而非荧光绿，天空粉蓝干净；肤色透亮保留血色。保留人物五官、姿势、服装与纵横比。禁 HDR、禁橙青调、禁死白、禁塑料皮肤。
```

### 窗边食物静物

```text
把这张食物照片修成日系奶油调：以侧窗柔光为光源，白盘与桌布呈奶白而非黄色，食物保持原有的新鲜色泽并微降饱和；阴影呈暖灰不发黑，整体低对比、安静温柔。保留食物的形态、摆盘与所有物件。禁过暖黄渍、禁死黑、禁新增道具。
```

### 阴天街角

```text
把这张街拍修成清新通透风格：保留阴天漫射光的低对比空气感，远处轻微亮灰形成空气透视；白墙干净微冷，绿植压成茶绿，招牌与衣物保留一个小面积焦点色；阴影雾面、无死黑。保留全部行人、车辆与建筑几何。禁 HDR 锐化、禁电影调、禁重绘内容。
```

### 海边青调

```text
把这张海边照片修成湿润青调：高光保持干净的白，海水与阴影注入青蓝灰青，沙滩呈浅暖灰；空气里有水分感但主体清晰；保留一处小面积暖色点缀（如救生圈或木栈道）。保留人物与地平线关系、原始纵横比。禁橙青对撞、禁死白天空、禁塑料肤色。
```

## 个人化映射

把用户的口语翻译成受控调整：

- **"再亮一点 / 再透一点"**——提中间调与阴影、增强沿光源的空气感；警告自己不要把高光推到裁切；
- **"太黄了 / 太脏了"**——白平衡回调中性，只在高光保留一丝模式倾向；
- **"颜色太艳"**——加大降饱和幅度，但先确认焦点色仍在；
- **"太寡了 / 没颜色"**——回调降饱和幅度，或把焦点色的局部饱和微升；
- **"要奶油一点"**——切换日系奶油模式，白平衡宁欠勿过；
- **"要日系青一点 / 要海边那种感觉"**——切换湿润青调，只动阴影与空气，高光保持白；
- **"皮肤再自然点"**——降低肤色暖度与对比，禁止磨皮感；
- **"别动构图 / 别裁"**——轻调档位，保留原始纵横比与全部元素；
- **"有胶片感但别太复古"**——只加极细颗粒与雾面阴影，禁 sepia、禁泛黄、禁粗颗粒；
- **"这是夜景"**——往干净的清晨蓝调方向收，禁霓虹感；若用户坚持明亮清新，先说明夜景与该风格天然冲突，再给出最接近的"室内灯光+微冷"方案。
